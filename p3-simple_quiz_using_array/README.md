# Nepal GK Quiz App

A simple Nepal General Knowledge Quiz App built using React. Users can answer multiple-choice questions, check correct answers, track their score, and restart the quiz.

## Features
- Multiple-choice questions about Nepal
- Instant answer feedback
- Score calculation
- Progress bar
- Final result display
- Restart quiz option
- Responsive design

## Technologies Used
- React
- JavaScript
- HTML
- CSS
- Vite

## Installation

```bash
git clone <your-repository-url>
cd quiz-app
npm install
npm run dev
```

## How to Play
1. Read the question.
2. Select an answer.
3. Click **Next Question** to continue.
4. View your final score after completing the quiz.
5. Click **Restart Quiz** to play again.
